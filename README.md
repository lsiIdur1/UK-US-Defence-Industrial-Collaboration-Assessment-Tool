# DICAS – Defence Industrial Collaboration Assessment System

## Note

This project uses mock and publicly generated data only. It does not contain or process any proprietary or sensitive information or concepts. It is intended for educational and prototyping use only. It is not designed for operational, military, procurement, legal, or safety-critical decision making.

DICAS is an experimental AI-assisted analytical system designed to transform unstructured source material into structured UK–US defence industrial collaboration assessments.

It generates multi-section analytical reports including executive summaries, strategic alignment analysis, industrial opportunity assessments, stakeholder analysis, supply chain risks, and economic security implications.

---

## ⚠️ Caution

This tool uses large language models to generate analytical text. Outputs may be incomplete, inaccurate, speculative, or hallucinated.

All analytical assessments generated by the system are synthetic and should not be treated as factual intelligence reporting or official policy advice.

Use with caution and independently validate outputs against reliable and authoritative sources.

---

## Overview

DICAS converts raw text input into a structured UK–US defence industrial collaboration assessment.

The system uses a structured analytical framework:

- Executive Summary  
- Key Intelligence  
- UK–US Alignment  
- Industrial Opportunities  
- Supply Chain Risks  
- Economic Security Implications  
- Stakeholder Analysis  
- Recommended Engagement  
- Confidence Assessment  

The system also generates a Strategic Opportunity Matrix which evaluates industrial capability areas against contextual indicators derived from the source material.

Each section is generated as structured analytical paragraphs and exported into a formatted PDF assessment document.

### Built with:
- Streamlit (UI layer)  
- OpenAI API (analysis engine)  
- ReportLab (PDF generation)  
- Python (core logic)

## Output Structure

Each generated report contains the following sections:

High-level overview of strategic and industrial developments.

### KEY INTELLIGENCE
Core industrial and strategic indicators extracted from the source material.

### UK–US ALIGNMENT
Assessment of bilateral strategic and industrial coordination factors.

### SUPPLY CHAIN RISKS
Risks affecting resilience, dependency, scalability, or continuity.

### STAKEHOLDER ANALYSIS

### CONFIDENCE ASSESSMENT
Assessment of analytical confidence and source quality.

## Strategic Opportunity Matrix

The system generates a Strategic Opportunity Matrix within the PDF report.

The matrix evaluates industrial capability areas using contextual indicators derived from the input material.

### Matrix Categories:
- UK Position  
- US Demand  
- Strategic Value  
- Feasibility  
- Score (/5)  

The scoring model calculates a cumulative weighted score based on the overall strategic strength of each capability area.

## Local Fallback Mode

If the OpenAI API is unavailable, the system automatically switches to a local fallback mode.

### This mode:
- Generates placeholder analytical structures  
- Maintains full report formatting  
- Preserves matrix generation capability  
- Ensures PDF generation still works  
- Allows offline testing of the pipeline
